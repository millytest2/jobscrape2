was invented. Find-and-replace `[[` to locate them.

verb with no number still beats an invented figure that fails a reference check.

standard section headings — all deliberate, so ATS parsers read them cleanly. Keep it that
way when you edit. Each runs roughly one page once placeholders are filled.
